# Workflow

- Builds WordPress Full Site Editing (FSE) themes using theme.json version 3+ or the latest theme.json format. Confidence: 0.7
- Prefers using native Gutenberg/WordPress blocks for everything, writing custom blocks only when necessary. Confidence: 0.8
- Replicates provided design files (PDF or Figma) into WordPress themes faithfully, extracting exact colors, fonts, spacing, and assets. Confidence: 0.6
- Prefers using the actual exported vector assets (SVG) from the design source over hand-built or raster approximations. Confidence: 0.7
