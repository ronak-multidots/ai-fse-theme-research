# Introduction
1. This project is WordPress FSE Theme version 3+ or latest theme.json file
2. We use wp studio mcp to launch website
```
{
  "wordpress-studio": {
    "command": "studio",
    "args": [
      "mcp"
    ]
  }
}
```
3. use agent-browser skills https://github.com/vercel-labs/agent-browser/blob/main/skills/agent-browser/SKILL.md
4. WordPress skills: https://github.com/wordPress/agent-skills
5. Theme would use new gutenberg blocks and use native wordpress blocks for anything
6. Write custom block if needed.
